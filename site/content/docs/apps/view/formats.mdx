```ts title="view-source.ts"
import { launch } from "@tooee/view";

const code = await Bun.file("src/index.ts").text();

await launch({
  contentProvider: {
    load: () => ({ code, format: "code", language: "typescript", title: "index.ts" }),
  },
});
```

Every content value has a `format` and the fields for that format. [View: content and providers](/docs/apps/view/content-and-providers#content-formats) lists the fields per format. This page covers what each renderer draws, the keys it adds, and the limits you meet on the way. `title` goes in the title bar with the format as its subtitle, and the status bar starts with `Format:`.

## Markdown

`markdown` holds the source text. View splits it into blocks: a heading, a paragraph, a list item, a code block, a table, a blockquote, or a rule. Each block is one row. `j` and `k` move block by block, search matches a block's source text, and `y y` copies it. Nested lists flatten into indented rows. HTML blocks are dropped. `L` toggles the gutter, which numbers blocks, and `Lines:` in the status bar counts source lines.

A fenced code block draws in a bordered box with syntax colours for the fence language. Its lines never wrap. When the block is wider than the terminal and the cursor is on it, `h` and `l` pan the block four columns at a time. `Shift` with the mouse wheel pans as well.

A `mermaid` fence draws the diagram with box characters. A diagram that fails to parse, runs past 300 lines, or is a flowchart with more than 32 edges falls back to the plain code block. A `diff` or `patch` fence draws as a Hunk block; [View: diffs](/docs/apps/view/diffs#diff-fences-in-markdown) has the options. [View: custom renderers](/docs/apps/view/custom-renderers#render-a-fence-type) shows how to register a fence type of your own.

### Images in markdown

```markdown
![Build graph](./assets/build-graph.png)
![[assets/build-graph.png]]
![[assets/build-graph.png|40x12]]
![[assets/build-graph.png|Build graph]]
```

The first line is standard Markdown. The other three are Obsidian embeds; the text after `|` is either a `width` or a `widthxheight` in terminal cells, or alternative text. A relative path resolves from `imageBasePath` on the content, or from the working directory when it is unset. `createFileProvider` sets `imageBasePath` to the folder of the file. An absolute path or a URL with a scheme is used as it is.

An image is 12 rows tall and as wide as the paragraph unless the embed sets a size. While it loads, the row shows `Loading image:` and the alt text. When it fails, the row shows `Image failed to load:` and the alt text or the path. The protocol is chosen the same way as for the [image format](#image).

### Links in markdown

Link text draws underlined. The `View` component takes `onMarkdownLinkActivate`, a handler for a left click on link text. It receives the `href` and the command context:

```tsx title="open-links.tsx"
import { runCliSession } from "@tooee/shell";
import { View, createFileProvider } from "@tooee/view";
import type { ReactNode } from "react";

await runCliSession(
  (): ReactNode => (
    <View
      contentProvider={createFileProvider("README.md")}
      onMarkdownLinkActivate={(href, ctx) => {
        ctx.toast?.toast({ level: "info", message: href });
        return true;
      }}
    />
  ),
);
```

Return `true` to mark the click as handled, so it does not move the cursor. `launch()` has no option for the handler in Tooee 0.8.0, so mount `View` with `runCliSession` from [Launch apps from TypeScript](/docs/apps/launch#run-your-own-session).

## Code and text

`code` takes `code` and an optional `language`. `text` takes `text`. Both draw one row per line with line numbers in the gutter; `L` toggles them. Search matches one line, `y y` copies the line under the cursor, and `v` with `j` or `k` selects lines for `y v`. `Cursor:` in the status bar is the zero-based line index.

`language` picks the tree-sitter grammar for the colours. OpenTUI 0.5 bundles grammars for `typescript`, `javascript`, `markdown`, and `zig`. Any other value draws plain text. [View files and pipes](/docs/cli/view#open-a-file) lists the extensions `createFileProvider` maps to a language. The text format is the code renderer without a language.

## Table

```ts title="recent-commits.ts"
import { parseTSV } from "@tooee/renderers";
import { launch } from "@tooee/view";

const log = await new Response(
  Bun.spawn(["git", "log", "-20", "--format=%h%x09%as%x09%an%x09%s"]).stdout,
).text();
const { columns, rows } = parseTSV(`sha\tdate\tauthor\tsubject\n${log}`);

await launch({
  contentProvider: { load: () => ({ columns, format: "table", rows, title: "Recent commits" }) },
});
```

`columns` is a list of `{ key, header?, align? }` and `rows` a list of objects keyed by `key`. The header row stays fixed while the rows scroll. Each row is one navigation row: `j` and `k` move between rows, search matches the tab-joined cells, `y y` copies one row as tab-separated text, and `y g` copies the whole table with its header line. The status bar shows `Rows:` and `Cols:`.

A cell can hold any JavaScript value. Strings, numbers, and booleans draw as text. A `Date` draws as its ISO string. `null` and `undefined` draw as empty cells. Other objects draw as JSON.

Column widths come from the header and a sample of up to 100 rows spread evenly across the table, clamped between 4 and 80 characters plus one space of padding on each side. When the columns overflow the terminal, columns of 20 characters or less keep their width and the wider columns share the rest in proportion. A column whose first ten values are mostly numbers is right-aligned; `align: "left"` or `align: "right"` on the column overrides the guess.

`parseTSV`, `parseCSV`, and `parseJSON` from `@tooee/renderers` turn text into `columns` and `rows`. `parseAuto` picks one: JSON when the text starts with `[` and parses as an array, TSV when the first line has a tab, and CSV otherwise. `tooee view --renderer table` and `createTableFileProvider` use `parseAuto`.

| Parser      | Rule                                                                                                                          |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `parseCSV`  | The first line names the columns. A field may be quoted with `"`, and a quote inside a quoted field is written `""`.          |
| `parseTSV`  | The first line names the columns. Fields split on tabs.                                                                       |
| `parseJSON` | An array of objects. The columns are the union of the keys in the order they first appear; a missing key gives an empty cell. |

An empty header becomes `column_N`. A repeated header gets a `_2` or `_3` suffix so every key stays unique. Blank lines are skipped.

## Image

```ts title="view-logo.ts"
import { launch } from "@tooee/view";

await launch({
  contentProvider: {
    load: () => ({
      fit: "cover",
      format: "image",
      src: "examples/assets/tooee-native-image.png",
      title: "tooee-native-image.png",
    }),
  },
});
```

| Field      | Values                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| `src`      | A file path, a `URL`, a `Uint8Array`, an `ArrayBuffer`, a `Blob`, or a `Response`.                                   |
| `fit`      | `fit` keeps the aspect ratio inside the area and is the default. `cover` fills the area and crops. `fill` stretches. |
| `protocol` | `auto` is the default. `kitty`, `sixel`, and `blocks` force one protocol.                                            |

With `auto`, OpenTUI uses the kitty graphics protocol when the terminal reports it, sixel when the terminal reports it and the cell size in pixels is known, and half-block characters otherwise. Inside tmux it uses blocks. A terminal that does not answer the capability query gets blocks too. `sixel` without a known cell size falls back to `blocks`.

The image fills the content area. The document behind it has one row that holds the path, so `y g` copies the path and the status bar shows `Format: image` alone. A file that cannot be read shows `Image failed to load:` and the path above the empty area. `createFileProvider` picks this format for `.png`, `.jpg`, `.jpeg`, `.gif`, and `.webp`.
