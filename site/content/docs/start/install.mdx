title: Install
description: Install the tooee command or add Tooee packages to a Bun project.
---

Tooee runs on [Bun](https://bun.sh). Install Bun first.

## Install the CLI

```bash
bun add --global @tooee/cli
tooee --help
```

`tooee --help` prints the commands and options. To run a command without a global install, use `bunx`:

```bash
bunx @tooee/cli view README.md
```

## Add packages to a Bun project

```bash
bun add @tooee/view @tooee/ask @tooee/choose
```

Each package lists `@opentui/core`, `@opentui/react`, and `react` as peer dependencies, and Bun installs them. Add them to your own `package.json` when you want to control their versions:

```bash
bun add @opentui/core @opentui/react react
```

Bun prints `incorrect peer dependency` warnings for `@opentui/core` and `@opentui/react` while it installs Tooee 0.8.0. The packages run with the versions Bun picks.

Custom apps use more packages: `@tooee/shell`, `@tooee/commands`, `@tooee/layout`, `@tooee/overlays`, `@tooee/panels`, `@tooee/router`, `@tooee/themes`, and `@tooee/config`. Add each one when a guide asks for it. The full list is in [Packages](/docs/reference/packages).

## Set the JSX options

Tooee components are OpenTUI JSX. Point TypeScript at the OpenTUI runtime in `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "noEmit": true,
    "skipLibCheck": true,
    "jsx": "react-jsx",
    "jsxImportSource": "@opentui/react",
    "types": ["bun"]
  },
  "include": ["*.ts", "*.tsx"]
}
```

`jsx` and `jsxImportSource` make `<box>` and `<text>` typecheck. `types: ["bun"]` needs the Bun type package:

```bash
bun add -d @types/bun typescript
```

A script that only calls `launch()` typechecks without the two `jsx` options. Add them before you write a component.

## Check the install

```ts title="view-readme.ts"
import { createFileProvider, launch } from "@tooee/view";

await launch({ contentProvider: createFileProvider("README.md") });
```

```bash
bun view-readme.ts
```

View opens `README.md`. Press `q` to quit.
