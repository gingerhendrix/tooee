Tooee is a set of terminal micro-apps built on OpenTUI. Use it when you want focused, interactive terminal interfaces for viewing content, asking for text, choosing from lists, or composing those pieces into custom tools.

## Start here

- [Getting started with the CLI](/docs/getting-started/cli) — install `@tooee/cli` and try the built-in terminal apps.

## Documentation status

This is a deliberately small documentation skeleton. Package guides, API references, and worked examples will be added as their public interfaces settle. Until then, the [Tooee repository](https://github.com/gingerhendrix/tooee) is the source of truth.
