## @tooee/clipboard

| Export | Signature | Behaviour |
| --- | --- | --- |
| `copyToClipboard` | `(text: string) => Promise<boolean>` | Writes the system clipboard. Uses `wl-copy` on Wayland, then `xclip` or `xsel` on Linux, `osascript` on macOS, and PowerShell on Windows. Resolves `false` when no tool is found or the tool exits with an error. |
| `copyToPrimary` | `(text: string) => Promise<void>` | Writes the primary selection on Linux with `wl-copy --primary`, `xclip`, or `xsel`. Writes the system clipboard on other platforms, or when no primary tool is found. |
| `readClipboardText` | `() => Promise<string \| undefined>` | Reads the clipboard as text. |
| `readClipboard` | `() => Promise<ClipboardContent \| undefined>` | Reads an image from the clipboard first, then text. The result has `data` and `mime`; text comes back as `text/plain`. |
| `readPrimaryText` | `() => Promise<string \| undefined>` | Reads the primary selection on Linux. Reads the clipboard on macOS and Windows. |

The `y` copy command and the paste commands in `@tooee/shell` call these functions. Call them yourself from a command handler that copies or pastes text of its own. [Documents](/docs/build/documents#copy) covers the built-in copy.

Types: `ClipboardContent`.
