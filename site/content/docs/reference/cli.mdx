```text
tooee <command> [options]
```

`tooee`, `tooee help`, `tooee --help`, and `tooee -h` print the usage text to stdout and exit with code 0. An unknown command prints `Unknown command: <name>` to stderr, prints the usage text to stdout, and exits with code 1.

Every command draws its screen on stdout and returns the terminal to its previous state when the screen closes. Redirecting stdout redirects the screen as well; see [Use the result in a script](/docs/cli/ask-and-choose#use-the-result-in-a-script).

## tooee view

```text
tooee view [file] [--renderer <name>]
```

| Argument or flag                                      | Meaning                                                        |
| ----------------------------------------------------- | -------------------------------------------------------------- |
| `file`                                                | A file or a directory. When omitted, View reads stdin.         |
| `--renderer <name>`, `-r <name>`, `--renderer=<name>` | Force a renderer: `markdown`, `code`, `text`, `table`, `diff`. |

| Case                       | Behaviour                                                                                                                                                                          |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File                       | Renderer from the extension; see the table in [View files and pipes](/docs/cli/view#open-a-file). A text file that holds a unified patch opens as a diff.                          |
| Directory                  | Opens the directory view. `--renderer` with a directory prints `--renderer cannot be used with directory view` and exits with code 1.                                              |
| stdin                      | Reads all of stdin. Renders it as markdown, or as a diff when it is a patch, unless `--renderer` is set. In 0.8.0 the session ends when stdin closes, before the content is drawn. |
| Unknown renderer           | Prints `Unknown renderer: <name>` and the list of values. Exit code 1.                                                                                                             |
| Missing renderer value     | Prints `Missing value for --renderer`. Exit code 1.                                                                                                                                |
| Second positional argument | Prints `Unexpected argument: <arg>`. Exit code 1.                                                                                                                                  |

View exits with code 0 after `q` or `ctrl+c`.

## tooee ask

```text
tooee ask [--single-line | --multiline] [prompt...]
```

| Flag                  | Meaning                                                                      |
| --------------------- | ---------------------------------------------------------------------------- |
| `--single-line`, `-s` | One-line input. `Enter` submits.                                             |
| `--multiline`, `-m`   | Multiline editor. `Shift+Enter` submits in insert mode. This is the default. |

Every other argument joins the prompt, separated by spaces. Without arguments, Ask shows the editor with no prompt line.

| Stream or code | Value                                                        |
| -------------- | ------------------------------------------------------------ |
| stdin          | Keyboard input. Piped stdin ends the session at once.        |
| stdout         | The submitted text followed by a newline. Nothing on cancel. |
| Exit code      | 0 on submit and on cancel.                                   |

## tooee choose

```text
tooee choose [--multi] [--prompt <text>]
```

| Flag              | Meaning                                           |
| ----------------- | ------------------------------------------------- |
| `--multi`, `-m`   | Multi-select. `Tab` and `Shift+Tab` toggle items. |
| `--prompt <text>` | Title bar text.                                   |

Other arguments are ignored.

| Stream or code | Value                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| stdin          | One item per line. Empty lines are dropped. Choose expects a pipe and reads keys from `/dev/tty` while stdin is piped.          |
| stdout         | One line per picked item, in the order the items were toggled, or the highlighted item when none is toggled. Nothing on cancel. |
| Exit code      | 0 on confirm. 1 on cancel.                                                                                                      |

## tooee table

```text
tooee table [file]
```

Deprecated. Behaves as `tooee view --renderer table [file]` and shares its stdin rule. Tooee 0.9.0 removes the command.

## Exit codes

| Code | When                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------- |
| 0    | Usage text printed; View closed; Ask submitted or cancelled; Choose confirmed.                                                |
| 1    | Unknown command; unknown or missing `--renderer` value; unexpected argument; `--renderer` with a directory; Choose cancelled. |
