```text
tooee <command> [options]
```

`tooee`, `tooee help`, `tooee --help`, and `tooee -h` print the usage text to stdout and exit with code 0. An unknown command prints `Unknown command: <name>` to stderr, prints the usage text to stdout, and exits with code 2.

Interactive commands separate terminal traffic from command data:

| Channel                     | Purpose                                            |
| --------------------------- | -------------------------------------------------- |
| process stdin               | Piped items or content                             |
| controlling terminal input  | Keyboard events when stdin is a pipe               |
| controlling terminal output | Alternate-screen drawing when stdout is redirected |
| process stdout              | Submitted text and selected values                 |
| process stderr              | Usage and startup errors                           |

When process stdin or stdout already points at a terminal, Tooee uses that stream directly. Each command restores the terminal when its screen closes. A session that needs `/dev/tty` and cannot open it prints an error to stderr and exits with code 2.

## tooee view

```text
tooee view [file] [--renderer <name>] [--outline]
```

| Argument or flag | Meaning |
| --- | --- |
| `file` | A file or a directory. When omitted, View reads stdin. |
| `--renderer <name>`, `-r <name>`, `--renderer=<name>` | Force a renderer: `markdown`, `code`, `text`, `table`, `diff`. |
| `--outline` | Open the heading outline beside Markdown content at start. Other formats ignore it. |

| Case | Behaviour |
| --- | --- |
| File | Renderer from the extension; see the table in [View](/docs/cli/view#open-a-file). A text file that holds a unified patch opens as a diff. |
| Directory | Opens the directory view. `--renderer` with a directory prints `--renderer cannot be used with directory view` and exits with code 2. |
| stdin | Reads all of stdin, then remains interactive through the controlling terminal. Renders as markdown or as a diff when it is a patch, unless `--renderer` is set. |
| Unknown renderer | Prints `Unknown renderer: <name>` and the list of values. Exit code 2. |
| Missing renderer value | Prints `Missing value for --renderer`. Exit code 2. |
| Second positional argument | Prints `Unexpected argument: <arg>`. Exit code 2. |

View exits with code 0 after `q` or `ctrl+c`.

## tooee ask

```text
tooee ask [--single-line | --multiline] [prompt...]
```

| Flag | Meaning |
| --- | --- |
| `--single-line`, `-s` | One-line input. `Enter` submits. |
| `--multiline`, `-m` | Multiline editor. `Shift+Enter` submits in insert mode. This is the default. |

Every other argument joins the prompt, separated by spaces. Without arguments, Ask shows the editor with no prompt line.

| Stream or code | Value |
| --- | --- |
| stdin | Keyboard input when it is a terminal. Piped data is ignored while keys come from `/dev/tty`. |
| stdout | The submitted text followed by a newline. Nothing on cancel. |
| Exit code | 0 on submit. 1 on cancel. |

## tooee choose

```text
tooee choose [--multi] [--prompt <text>]
```

| Flag              | Meaning                                           |
| ----------------- | ------------------------------------------------- |
| `--multi`, `-m`   | Multi-select. `Tab` and `Shift+Tab` toggle items. |
| `--prompt <text>` | Title bar text.                                   |

Other arguments are ignored.

| Stream or code | Value |
| --- | --- |
| stdin | One item per line. Empty lines are dropped. Choose expects a pipe and reads keys from `/dev/tty` while stdin is piped. |
| stdout | One line per picked item, in the order the items were toggled, or the highlighted item when none is toggled. Nothing on cancel. |
| Exit code | 0 on confirm. 1 on cancel. |

## Exit codes

| Code | When |
| --- | --- |
| 0 | Usage text printed; View closed; Ask submitted; Choose confirmed. |
| 1 | Ask or Choose cancelled without a confirmed result. |
| 2 | Invalid arguments, an unknown command, no usable controlling terminal, or another startup error. |
